# Локализация программных модификаций форм: внешние примеры ERP

Эта справка указывает на примеры организации общей библиотеки изменений форм в отдельном проекте; исходный BSL-код здесь не воспроизводится.

## Когда открывать

Используй, когда сравниваешь централизованную диспетчеризацию изменений по типам форм и общие вспомогательные процедуры для программного добавления элементов.

## Как применять

1. Сначала выбери механизм изменения типовой формы; общая библиотека сама по себе не подтверждает, что её вызов допустим или достижим для нужной формы.
2. Проверь в целевом релизе типы элементов, доступные свойства и методы, сигнатуры процедур и серверный/клиентский контекст.
3. Для структурных изменений `Form.xml` используй отдельный маршрут работы с формой; динамическое добавление элементов не заменяет декларативную модификацию, когда она требуется.

В репозитории-источнике не указана лицензия. Здесь сохранены только названия и ссылки; фрагменты исходного кода не копировались.
