# События и модуль формы: внешние примеры ERP

Эта справка указывает на примеры из отдельного проекта; исходный BSL-код здесь не воспроизводится.

## Когда открывать

Используй при анализе обработчика события формы, передачи управления из модуля формы в общие модули и фактической цепочки до точки расширения.

## Источники

- [README проекта](https://github.com/Chif13-Korsh/ChangingFormsProgERP/blob/413998b35a231d8b918c199fc55affcefbc37b14/README.md) — авторское описание подхода для ERP и предполагаемой цепочки `ПриСозданииНаСервере`.
- [1. Пример модуля формы](https://github.com/Chif13-Korsh/ChangingFormsProgERP/blob/413998b35a231d8b918c199fc55affcefbc37b14/ПримерыКода/1.ПримерМодуляФормы.bsl) — пример обработчика создания формы с дополнительной инициализацией и вызовом общего модуля событий.
- [2. События форм](https://github.com/Chif13-Korsh/ChangingFormsProgERP/blob/413998b35a231d8b918c199fc55affcefbc37b14/ПримерыКода/2.СобытияФорм.bsl) — пример диспетчеризации события формы и вызовов из общих модулей, включая точку `МодификацияКонфигурацииПереопределяемый`.

## Как применять

1. Рассматривай эти материалы как пример конкретного решения для ERP, а не как контракт платформы или гарантию для другой конфигурации.
2. В исходниках целевой версии проверь вызывающую форму, промежуточные общие модули, условия вызова, директивы компиляции и точную сигнатуру.
3. Не переноси порядок вызовов и ранние выходы из примера без проверки роли типовой и собственной логики формы.

В репозитории-источнике не указана лицензия. Здесь сохранены только названия и ссылки; фрагменты исходного кода не копировались.
